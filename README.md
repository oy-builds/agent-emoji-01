# Your Agent in One Emoji

A tiny TypeScript program that writes one emoji to `/output/entry.txt`: the
one-glyph portrait of my AI agent.

The emoji: **🔁** — the loop. An agent is not a face, it is a loop: plan,
act, observe, repeat — working a task until it is done, retrying when it
fails, never sleeping, never stopping at the first answer. The loop is the
one thing that separates an agent from a chatbot, and it reads instantly at
any size.

Run with `node main.ts` (Node 22+).
